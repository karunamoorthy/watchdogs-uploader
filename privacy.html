Privacy policy

Watchdogs Uploader. Last updated: 11 November 2026.

Summary

Watchdogs Uploader is a private tool used only by its owner to upload videos to the owner's own YouTube channels. It does not collect data from other people.

What the tool accesses

With the owner's permission, the tool uses the YouTube API to:

  • upload videos to the owner's channels and set their title, description, visibility and publishing time;
  • read the name of the channel it is connected to;
  • read statistics of the owner's videos, such as views, likes and comments counts.

What is stored, and where

  • The sign-in token that Google issues is stored in a file on the owner's own computer. It is not sent anywhere except to Google when the tool calls the YouTube API.
  • Video statistics are saved on the owner's computer. A summary of them (video titles, publishing times, view counts and the status of the daily run) may be copied to a private database that only the owner can sign in to, so the owner can view it on a phone.

Sharing

Data obtained through the YouTube API is not sold, not shared with third parties and not used for advertising. It is used only to run and monitor the owner's channels.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the computer has the same effect for that computer.

YouTube and Google

The tool uses YouTube API Services. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.
